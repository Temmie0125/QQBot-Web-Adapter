表情包操作提示

          
    
            
  • 新建列表：点击标题栏右侧「+」可新建表情包列表，可设置标题与图标图片。
    • 
            
  • 添加表情：进入列表后，点击网格左上角虚线「+」单元，可添加单个表情图片，或选择 .zip 压缩包批量导入（支持 png/jpg/gif/webp/bmp/svg）。
    • 
            
  • 移动位置：长按列表或表情并拖动。落在目标中间即插入到其前后；拖到目标正上方（中心）则与之交换位置（替换位置）。
    • 
            
  • 修改列表：右键列表 → 「修改设置」，可修改标题与图标图片。
    • 
            
  • 选中 / 批量删除：右键表情 → 「选中」进入勾选模式，其余表情显示未勾选圆孔，点击可切换；底部「删除」一键删除勾选，「取消」退出。
    • 
            
  • 删除：右键列表可删除整个列表；右键表情「删除」可删除单张。
    • 
            
  • 发送：普通/MD 消息中点击表情直接作为图片插入；Ark 模板中会先上传到图床再填入链接。
